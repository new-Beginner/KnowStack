## 实现边界

新增 `report_outdated_memory`：工具必须使用同一会话、同一轮次内 `read_memory` 返回的有效凭据，报告 1～3 条已有记忆的 ID、原因与具体依据。标题与原文由服务从读取快照获取，报告前重读并比较原生快照及会话项目归属。

报告模块只接收原生读取接口，没有原生保存或删除接口。模型工具仍不支持删除、改写、替换或归档；即使开启自动保存也只影响新记忆。提示词明确禁止模型借助界面自动化、Shell 或其他工具代删，用户自行决定并操作。

卡片只有“打开记忆并定位”“本次忽略”：

- 打开时重新核验原会话、项目组与目标原文，编辑器固定定位该项目，不随当前活动聊天切换；首次加载再次核验原文和会话。
- 每次重新读取保持固定项目身份；项目组被替换不会重定向到新组。保存仍复用原编辑器的归属复核、快照比较及回读验证。
- 仅打开不会修改草稿；用户确认删除只改草稿，点击“保存记忆”才写入原生记忆。
- 忽略仅改变临时提醒状态。同会话、同项目、同 ID 与同原文在本次插件加载期间去重，不随轮次或报告措辞变化重复提醒；不同会话独立判断。
- 操作有效期 15 分钟，插件重载后失效。聊天历史可能保留报告文本，不代表后端提醒仍有效。没有持久待办、第二套记忆文件或后台模型。
- 记忆被修改或不存在后，旧提醒停止定位；不声称“模型已删除”。读取失败时禁用定位，不能把失败解释为空项目。

证据真实性、语义适用范围和最终是否过时仍需要模型与用户判断；代码只验证字段、ID、原文和绑定关系，不声称能自动证明自然语言证据。仅时间较早、未使用或适用条件不同不构成过时依据。

## 可重复运行的检查

在项目根目录运行，要求 Node.js 22+ 和本机 Chrome：

```bash
node --test tests/*.test.cjs
node tests/outdated-cdp.cjs
node tests/memory-input-cdp.cjs
```

可设置 `CHROME_PATH` 指定 Chrome；`KNOWSTACK_SCREENSHOT_DIR` 可将截图导向临时目录，避免改写历史截图。临时 Chrome 配置保存在 `PI_SCRATCH_DIR`（未设置时为系统临时目录）。

源码语法检查包含正式入口、服务、扩展、全部 Renderer 模块和测试脚本。插件使用 `PluginCheck(directory=".")` 验证，再由 `PluginPack(directory=".")` 打包，不手工压缩。现有高风险权限需要用户授权，但本版没有新增权限。

## 用户安装测试步骤

### 1. 安装并刷新 Agent

安装 `dist/local.project-memory-api-probe-0.5.0.piplug`，确认插件列表版本为 0.5.0。沿用插件 ID `local.project-memory-api-probe`，升级而不是另装一份。重新加载插件后重启当前会话 Agent，或新建 Agent 会话；工具目录可能需下一轮消息刷新。

若找不到 `plugin_local_project_memory_api_probe_report_outdated_memory`，先检查注册版本、插件加载状态及 Agent 是否已重启。不要通过改动旧记忆来测试工具是否存在。

### 2. 准备可丢弃的测试记忆

在测试项目的项目记忆编辑器中，手动添加并保存：

- 标题：过时提醒测试
- 内容：测试约定：本项目构建继续使用旧脚本 legacy-build。此条仅供提醒功能验收。

另准备一条“保留测试规则”，用于检查其他记忆保持不变。不要使用重要项目规则试删。

### 3. 触发只读提醒

在同一项目发送：

```text
我明确确认标题为“过时提醒测试”的测试约定已经废弃。
请读取当前项目最新原生记忆，只对这条测试记忆调用 report_outdated_memory 生成疑似过时提醒。
依据写明本轮用户明确废弃该测试规则。不要删除、改写或新增任何记忆，也不要代我点击界面。
```

预期：出现卡片，展示准确原文、原因、依据及两个按钮；重新打开项目记忆时原条目仍在。保持自动保存开启也应如此。

### 4. 检查用户决策路径

- **忽略**：点“本次忽略”，原记忆不变。同一会话下一轮再次报告同一原文应跳过，不生成重复提醒。要继续测定位，可新建会话，或重载插件并重新读取报告。
- **定位**：点“打开记忆并定位”，应固定显示正确项目并高亮“过时提醒测试”；保存按钮初始禁用，原条目和保留条目均存在。
- **取消删除**：点高亮条目删除按钮，取消确认，条目不变。
- **仅删草稿**：再次删除并确认，不点保存；关闭并放弃修改后，原记忆仍在。
- **用户保存删除**：重新报告／定位后，由你确认删草稿并点“保存记忆”，才移除测试条目；保留条目不变，成功后显示回读验证结果。
- **变化／失效**：报告后先在其他窗口修改目标原文，再点旧提醒，不能定位旧原文；会话换项目也不能定位到另一项目。重载插件后旧卡片应失效，不能自动执行任何操作。

## 已知限制

原生记忆保存仍使用宿主内部 Renderer IPC 和整表保存，不是原子比较并保存；避免多个窗口或插件同时保存记忆。DOM 与内部 IPC 的宿主兼容性、实际工具卡挂载和安装后交互，需要上述实机验收。自动发现疑似过时内容依赖 Agent 遵循指引，不保证每轮必定提醒，也不进行后台全库巡检。
