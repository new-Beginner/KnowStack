# KnowStack 0.6.0 逐项修改与验证

> **当前状态：本地源码与模拟环境验证通过，实际宿主尚未完成 reload 验收。**
>
> 本版改用正式内嵌侧栏，需要普通 `ui.view` 展示权限。宿主实际日志明确拒绝自动热更新：`PERMISSION_DENIED: manifest now requests ui.view; reload it from the Plugins page to review`。本轮只读实机检查返回 `RENDERER_NOT_READY`。没有绕过授权，也没有用真实项目记忆试改、试删或测试写入。
>
> 截图中历史 `HOST_CALL_FAILED` 的原始宿主原因没有足够日志，**不能声称已确认它的唯一根因或保证所有宿主故障不再发生**。以下区分已经复现并修复的插件缺陷与尚待实机确认的部分。

## 1. 故障根因与修复证据

### 已确认的缺陷

| 证据 | 发现 | 修复落点 |
| --- | --- | --- |
| 新测试在旧实现得到 `HOST_CALL_FAILED`，而模拟宿主明确返回 `NOT_FOUND` | 原生桥的 catch 和响应检查统一丢掉公开错误码及接口步骤，历史回执不足以追溯底层异常 | `renderer/host-call.mjs`；`renderer/native-memory.mjs`；`renderer/memory-editor.mjs` |
| 并发 `next` 复现测试实际领取数为 2，预期 1；修复后通过 | 检查 claimed 之后先 await 设置，再标记领取；两个渲染器可同时越过检查 | `memory-service.js`：在任何异步开关检查之前同步占用任务，再核对过期及存在性 |
| 瞬态、永久错误与保存响应丢失用例 | 旧代码没有区分可恢复的只读瞬态失败与不可重放的写入 | 只对明确 `TIMEOUT` / `IPC_TIMEOUT` / `BUSY` / `UNAVAILABLE` 的同一只读请求最多恢复一次；永久错误、未知错误和所有保存均不自动重试 |

返回只包含允许的公开错误码与固定 `errorStep`，不回传私有宿主错误正文、路径堆栈或消息内容。保存可能发生但未能确认时仍为 `unverified`，阻止该目标继续写入，不回滚整表、不盲目重发。

宿主会话正文截断实现按字符处理；本轮核对后排除了“1 字符限制截断中文导致失败”的猜测。没有把未证实假说写成根因。

### 尚未确认

原截图只有通用错误码，没有具体失败接口、时间点或原始宿主异常。现有相关历史日志也不能与截图中的底层失败一一对应。新的诊断和有限恢复覆盖了已验证缺陷，但不能代替历史异常的真实复现。reload 后若仍失败，应以新版回执的公开错误码和步骤继续定位，而不是反复重试写入。

| 用户要求 | 当前实现 | 对应证据与范围 |

| 7. 正常插件开发、本地 reload | 保留原插件 ID，版本及 Renderer 握手升到 0.6.0，生成同版本包；只新增普通 `ui.view`，未申请文件/网络/桌面/更广会话权限 | `PluginCheck` 通过；`PluginPack` 用标准工具生成。没有修改宿主或数据库，也没有绕过新权限。正常 reload/授权和真实侧栏行为尚未验收 |

## 4. 本地生效与剩余验收

1. 保存好侧栏内未提交草稿，在插件页对当前本地 KnowStack **reload**；由宿主正常确认新增 `ui.view` 权限。拒绝时不应绕过或扩大授权。
2. 重启当前 Agent，核对新增 `update_memory` / `delete_memory` 及长期知识提示词。旧模型上下文不会因为磁盘源码更新就自动改写。
3. 打开本地测试项目的活动会话，在工作面板“新建 → 项目记忆”确认出现正式内嵌标签；切换浏览器/记忆标签，不应弹出独立窗口。
4. 在设置和侧栏分别切换自动保存/模型删除，验证另一处同步，重载后选择保留；不要用重要记忆试删。
5. 在可丢弃测试条目上检查：删除关闭时模型拒绝，开启时能按证据删除；自动保存关闭时修改仍可用并保留原 ID；仅有进度/测试数量时不应新增长期记忆。测试数据由用户自行清理。
6. 若读取失败，保留新版公开错误码和步骤继续调查；任何不确定写入都先检查原生记忆，不盲目重放。

底层仍是宿主原生整表保存。本插件内串行、快照核验和回读不能替代跨其他窗口/插件的原子比较并交换。侧栏目前需要活动本地会话；关闭或宿主驱逐视图、reload 可能销毁未保存草稿。插件商店审核、最旧宿主和其他平台没有实测，不能由本轮模拟检查推断。

本轮保留已有未提交更改，没有 Git 提交、推送、自动安装或真实记忆改删。长期知识策略是后续模型调用契约，不是保证所有模型必然遵循的分类器。
